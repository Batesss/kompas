# Как запустить сайт «Поисковик работ»

## 1. Ключ Claude
1. Зайди на https://console.anthropic.com и зарегистрируйся.
2. Billing: привяжи карту и пополни баланс на $5–10.
3. API Keys → Create Key → скопируй ключ (начинается с `sk-ant-`). Он показывается один раз.

## 2. Ключи Stripe
1. https://dashboard.stripe.com → Developers → API keys.
2. Скопируй **Secret key**. Для проверки бери ключ из Test mode (`sk_test_...`), для настоящих денег — `sk_live_...`.

## 3. Залить код на GitHub
1. https://github.com → New repository → название `poisk-raboty` → Private → Create.
2. «uploading an existing file» → перетащи **все файлы из архива** (папку `public` тоже) → Commit.

## 4. Railway
1. https://railway.com → New Project → Deploy from GitHub repo → `poisk-raboty`.
2. В сервисе: **Settings → Networking → Generate Domain**. Получишь адрес сайта.
3. **Правый клик по сервису → Attach Volume**, путь: `/data`. Там хранятся заказы и подборки.
4. **Variables** — добавь:

| Имя | Значение |
|---|---|
| `ANTHROPIC_API_KEY` | ключ из шага 1 |
| `STRIPE_SECRET_KEY` | ключ из шага 2 |
| `PRICE_CZK` | цена в кронах, например `149` |
| `DATA_DIR` | `/data` |

## 5. Вебхук Stripe (чтобы поиск запускался, даже если клиент сразу закрыл страницу)
1. Stripe → Developers → Webhooks → Add endpoint.
2. URL: `https://ТВОЙ-АДРЕС/webhook/stripe`, событие `checkout.session.completed`.
3. Скопируй **Signing secret** (`whsec_...`) → в Railway переменная `STRIPE_WEBHOOK_SECRET`.

## 6. Письма на email (по желанию)
Чтобы письма уходили клиентам, нужен свой домен (около 10 € в год).
1. https://resend.com → добавить и подтвердить домен.
2. В Railway: `RESEND_API_KEY` = ключ Resend, `EMAIL_FROM` = `Компас <noreply@твой-домен>`.
Без этого всё работает, просто подборка будет только на сайте по личной ссылке.

## Проверка
- В Stripe Test mode плати картой `4242 4242 4242 4242`, срок любой будущий, CVC любой.
- Сделай 2–3 поиска и посмотри, нравятся ли подборки.
- Потом замени ключ Stripe на `sk_live_...` и сделай новый вебхук в Live mode.

## Полезное
- Сменить цену — переменная `PRICE_CZK`.
- `FREE_MODE=1` — поиск без оплаты (только для своих проверок, **не оставлять включённым**).
- Если поиск упал — у клиента на странице кнопка «Спробувати ще раз», оплата не теряется.
- Логи — Railway → Deployments → View logs.
